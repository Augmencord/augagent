# Security Policy

## Supported Versions

Currently, only the latest release of `augagent` receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0.0| :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `augagent`, please send an email to **augmencord@gmail.com**. All security vulnerabilities will be promptly addressed.

We appreciate your effort and responsible disclosure and will make every effort to acknowledge your contributions.
